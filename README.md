# GetinOxySpacer — Web v03

Correção da exibição de vídeos: o elemento de vídeo usa `object-fit: contain` dentro de uma área de altura limitada, preservando a imagem inteira sem cortes, incluindo vídeos verticais. Botão **Reproduzir / Pausar** fica visível abaixo do vídeo, além dos controles HTML5 nativos. O botão **Reiniciar vídeo** foi mantido.

## Atualização no GitHub

Substitua os arquivos `index.html`, `styles.css` e `app.js` do repositório GitHub Pages pelos arquivos desta versão, na raiz da branch `main`. O arquivo `.nojekyll` pode ser mantido. Aguarde a publicação em **Actions** ou **Settings > Pages** e atualize a página com **Ctrl+F5**.

## Funcionamento

Abra a URL do GitHub Pages, entre com a senha já configurada, selecione a pasta local dos vídeos MP4 e utilize os controles abaixo do vídeo.

**Segurança:** a senha embutida no JavaScript é apenas uma barreira visual, não um login seguro. Nunca publique vídeos ou dados pessoais no repositório. O acesso à pasta usa as permissões do navegador (Chrome ou Edge).
